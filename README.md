# Amari Valennoire

Play sheet for Amari, a level 11 elf bladesinger (D&D 2024), as an installable app.

Open https://cupofautie.github.io/Amarielle-Valennoire/ in Chrome on Android, then menu, "Add to home screen" / "Install app".
It works offline. Character data is saved only on the device; use Traits, "App data" to back up or restore.

This repository is generated from the site source kept in the Claude project; don't edit `index.html` here by hand.
